# DigiPaga AI

Autonomous commerce agent for creators in Latin America.

**Hackathon:** Programmable Money Hackathon — Arc × Circle — Agentic Economy Track

> "Connect your social profile. AI finds campaigns. Someone buys. You instantly receive USDC."

## Stack
Next.js 15 · React 19 · TypeScript · TailwindCSS · shadcn/ui · Framer Motion  
Circle Agent Stack · Arc Testnet · Privy Auth · Turborepo · pnpm

## Run locally
\`\`\`bash
pnpm install
cp .env.example .env
pnpm dev
\`\`\`
